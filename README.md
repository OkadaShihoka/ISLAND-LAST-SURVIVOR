## 🚀 初心者向けセットアップ＆デプロイ手順

### ステップ1: Google スプレッドシートの新規作成
1. ブラウザで [Google スプレッドシート](https://sheets.google.com/) を開きます。
2. **「空白のスプレッドシート」** を新規作成します。
3. シート名を `ISLAND_DB` など任意の名前に変更します。

---

### ステップ2: Apps Script エディタの起動とファイル配置
1. スプレッドシート上部メニューの **「拡張機能」** ＞ **「Apps Script」** をクリックします。
2. スクリプトエディタが開きます。左上のプロジェクト名を `IslandSurvivor` に変更します。

#### ① `Code.gs` の貼り付け
1. 既存の `コード.gs`（または `Code.gs`）の内容を全選択して削除します。
2. 本プロジェクトの `Code.gs` の内容をすべてコピーして貼り付けます。
3. **※ スプレッドシートIDの設定**:
   - 今回はスプレッドシートとスクリプトが直結（コンテナバインド）しているため、`var SPREADSHEET_ID = '';` のままで自動認識します！

#### ② `css.html` の作成
1. エディタ左側のファイル一覧にある **「＋」**（ファイルを追加）をクリックし、**「HTML」** を選択します。
2. ファイル名に `css` と入力して Enter を押します（`css.html` が作成されます）。
3. 本プロジェクトの `css.html` の内容をコピーしてすべて貼り付けます。

#### ③ `js.html` の作成
1. 同様に **「＋」** ＞ **「HTML」** を選択します。
2. ファイル名に `js` と入力して Enter を押します。
3. 本プロジェクトの `js.html` の内容をコピーしてすべて貼り付けます。

#### ④ `index.html` の作成
1. 同様に **「＋」** ＞ **「HTML」** を選択します。
2. ファイル名に `index` と入力して Enter を押します。
3. 本プロジェクトの `index.html` の内容をコピーしてすべて貼り付けます。

4. キーボードの `Ctrl + S`（Macは `Cmd + S`）を押して、すべてのファイルを保存します。

---

### ステップ3: データベースの初期化 (初回のみ)
1. スクリプトエディタ上部の実行関数選択プルダウン（通常は「doGet」と表示）をクリックし、**`setupDatabase`** を選択します。
2. **「▷ 実行」** ボタンをクリックします。
3. **初回のみ「承認が必要です」というダイアログが表示されます**:
   - **「権限を確認」** をクリックします。
   - お使いの Google アカウントを選択します。
   - 「Google はこのアプリを検証していません」という警告画面が出たら、左下の **「詳細」** をクリックし、一番下の **「IslandSurvivor（安全ではないページ）に移動」** をクリックします。
   - **「許可」** をクリックします。
4. 実行ログに「実行完了」と表示されれば成功です！
5. 元のスプレッドシート画面を確認すると、`Players`, `Islands`, `Members`, `Inventory`, `SharedInventory`, `Items`, `Recipes`, `Events`, `Logs`, `Messages`, `Buildings`, `Achievements` の**12シートが自動生成**され、初期マスターデータが投入されています。

---

### ステップ4: ウェブアプリとしての公開（デプロイ）
1. スクリプトエディタ画面の右上にある青い **「デプロイ」** ボタン ＞ **「新しいデプロイ」** をクリックします。
2. 左側の歯車アイコン（種類の選択）をクリックし、**「ウェブアプリ」** を選択します。
3. 以下の項目を設定します：
   - **説明**: `v1.0 初期リリース` （任意）
   - **次のユーザーとして実行**: `自分（あなたのメールアドレス）`
   - **アクセスできるユーザー**: **`全員`** （※重要：マルチプレイのフレンドが遊べるように必ず「全員」を選択してください）
4. 右下の **「デプロイ」** ボタンをクリックします。
5. デプロイが完了すると、**「ウェブアプリの URL」**（`https://script.google.com/macros/s/.../exec`）が表示されます！
6. **「コピー」** をクリックして URL を保存します。

## 🎮 ゲームの遊び方

1. **アクセス**: コピーしたウェブアプリ URL をブラウザ（Chrome, Safari等）で開きます。
2. **プレイヤー登録**:
   - 名前を入力し、4つの役割（EXPLORER / HUNTER / CRAFTSMAN / MEDIC）から選択します。
3. **島を作る（ホスト）**:
   - 「新しい島を作る」を選び、島名を入力します。
   - 発行された **6桁の招待コード** を仲間にLINEやDiscordで共有します。
4. **島に参加する（フレンド）**:
   - 「フレンドの島に参加する」を選び、招待コードを入力して合流します。
5. **生存活動**:
   - 探索で素材（木材、石、食料、水、薬草、鉱石）を集めます。
   - 個人アイテムを「共有倉庫」に預け、全員で拠点設備（焚き火、テント、小屋、貯水設備、いかだ）を建築します。
   - 時間帯が進むと空腹と渇きが進行するため、木の実や魚、真水で生存を維持します。
6. **脱出＆勝利**:
   - 脱出用いかだを Lv.3 まで完成させ、共有倉庫に水10個、食料10個を備蓄して「脱出する！」を実行すれば、全員でクリアとなります！
